## 3. 功能优先级说明
- **P0（核心必选，第一批交付）**：
  - 邮箱验证码登录与“登录即注册”无感建档（Supabase Auth）；
  - 商机发现核心工作台（数据源切换、关键词输入、评论开关、视频数 5~20、评论数 10~100 滑块、成本预估计算）；
  - 异步任务执行与进度状态轮询感知；
  - 后端 TikHub 采集适配、评论聚类、Qwen/GLM 大模型深度分析；
  - 结构化商机报告呈现与全屏查看模式；
  - 商机历史列表记录与结果回溯；
  - 集中式配置文件（含中文注释）与集中式 Prompt 文件；
  - 第三方品牌全面清理与新品牌植入；
  - PC 端与移动端自适应响应式布局与高品质 UI。
- **P1（重要增强，第二批交付）**：
  - 报告导出 Markdown/HTML 并上传 MinIO 存储桶；
  - 历史记录关键词搜索过滤与历史记录删除；
  - 健康检查 `/api/health` 依赖组件连通性体检。
- **P2（未来规划扩展）**：
  - 更多社交平台（Bilibili、小红书等）深度爬虫扩展；
  - 多语言切换（中/英国际化）。
